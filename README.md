# 🌦️ Weather Forecasting Using Data Mining Techniques

## 📌 Project Overview
Weather Forecasting Using Data Mining Techniques is a machine learning-based project that predicts future weather conditions by analyzing historical weather data. The system uses data mining and predictive analytics techniques to identify patterns in temperature, humidity, rainfall, wind speed, and atmospheric pressure data.

The project aims to provide accurate weather predictions that can assist in agriculture, transportation, disaster management, and daily planning.





## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


---

## 📂 Dataset
The dataset contains historical weather information such as:
- Temperature
- Humidity
- Rainfall
- Wind Speed
- Atmospheric Pressure

Data can be obtained from public weather repositories or meteorological databases.
